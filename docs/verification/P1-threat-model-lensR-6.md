PROBES
- Probe G (would the rubric pass a bad version of this TM?) → YES, two ways. (1) MC-40(c) asks only that an input *exists* as an artefact with an owner, not that it *carries the mutant's signal at the stated capture point*. A TM whose leak detection reads a passive tap of TLS traffic (D5), or whose exfiltration detection relies on statement-level DB audit for row reads (D6), passes (c) by citation. Proposed patch: MC-40(c) "… and the input, at its stated capture point, carries the discriminating signal of the named mutant (for example plaintext parameters, row-level reads)". (2) MC-40(f) says "a detection of adapter compromise can't rely on a **PAUSE** the adapter enforces". A TM that ends every compromised-adapter detection in **QUARANTINE** (D3) passes a literal reading. Proposed patch: "PAUSE, QUARANTINE or any other fail-closed action".
- Probe F (would the rubric fail a good version?) → YES, in one place. MC-40(e) requires "every input is in that executor's declared input set (ADR-008 input model)", but only the monitor has a declared input set. A good TM that correctly names "deploy tooling" for DR-27 or "CI" for DR-20's CI half has no set to check against, so a literal reading fails it. Proposed rewording: "… in that executor's declared input set where one exists (ADR-008 for the monitor, ADR-001 for the signer); for any other executor, the detection row lists its inputs".
